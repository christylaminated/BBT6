# Cadence Timeseries RNN Demo

This repo includes a minimal vanilla RNN in `rnn_simple.py` that learns to predict next-step `Vout` from sliding windows built over `processed_waveforms.csv` generated by `main.py`.

## Prerequisites
- macOS or Linux
- Python 3.11 recommended (used in the demo below)
- CSVs present in this folder, especially `processed_waveforms.csv`

## Quick Start (Fast Demo)
Run these from the project folder:

```bash
python3.11 -m venv .venv311
source .venv311/bin/activate
python -m pip install --upgrade pip
# Minimal deps
pip install pandas numpy matplotlib scikit-learn
# CPU-only PyTorch (compatible build for macOS x86_64)
pip install torch --index-url https://download.pytorch.org/whl/cpu
# If NumPy 2.x is installed, downgrade to 1.x to avoid runtime issues with torch 2.2.x
pip install "numpy<2" --upgrade --force-reinstall

# Run the fast demo on CPU
python rnn_simple.py --demo --device cpu
```

You should see 3 epochs printed with Train/Val MSE and then a final Test MAE.

Example output snippet:
```
Epoch 001 | Train MSE: 0.83xxxxx | Val MSE: 1.18xxxxx
Epoch 002 | Train MSE: 0.82xxxxx | Val MSE: 1.14xxxxx
Epoch 003 | Train MSE: 0.76xxxxx | Val MSE: 1.10xxxxx
Test MAE: 0.65xxxxx
```

## What the demo does
- Loads `processed_waveforms.csv`
- Splits by `sim_id` into 70/15/15 train/val/test (deterministic by seed)
- Builds sliding windows of length `seq_len` over features (excluding `sim_id`, target is `Vout` at next step)
- Trains a vanilla `nn.RNN` with MSE loss; optimizer Adam
- Saves the best checkpoint and test predictions

## Outputs
Created under `outputs_simple/`:
- `best_rnn.pt` — best model by validation MSE
- `test_preds.csv` — columns: `sim_id, t_s, y_true, y_pred`
- `pred_vs_true_first_sim.png` — quick plot for the first test `sim_id`

## CLI Options
```
python rnn_simple.py [--data_path processed_waveforms.csv]
                    [--seq_len 32]
                    [--batch_size 128]
                    [--epochs 10]
                    [--lr 1e-3]
                    [--hidden_size 64]
                    [--num_layers 1]
                    [--device auto|cpu|cuda]
                    [--seed 42]
                    [--demo]
                    [--out_dir outputs_simple]
```

Common runs:
```bash
# Fast demo
python rnn_simple.py --demo

# Force CPU
python rnn_simple.py --demo --device cpu

# Full baseline
python rnn_simple.py --epochs 10 --seq_len 32 --batch_size 128 --device cpu
```

## Data Assumptions
`processed_waveforms.csv` contains at least:
- `sim_id` (group id), `t_s` (time)
- Numeric features: e.g., `VinA, VinB, dVout_dt, tau_f_est, tau_r_est, Rn_ohm, Rp_ohm, Cload_fF, Vdd, tempC`, one-hot columns like `gate_*`, `process_*`
- Target: `Vout`

Notes:
- Data is already scaled where appropriate by `main.py`. The model does not rescale.
- `sim_id` is excluded from input features and used only for splitting/metadata.

## Troubleshooting
- zsh: command not found: python → use `python3.11` or `python3`, or activate the venv: `source .venv311/bin/activate`.
- ModuleNotFoundError: No module named 'torch' → ensure you ran the install step:
  ```bash
  pip install torch --index-url https://download.pytorch.org/whl/cpu
  ```
- RuntimeError: Numpy is not available / NumPy 2.x compatibility issues →
  ```bash
  pip install "numpy<2" --upgrade --force-reinstall
  ```
- No valid sequences found → your groups may be shorter than `seq_len+1`. Try a smaller window:
  ```bash
  python rnn_simple.py --demo --seq_len 8 --device cpu
  ```

## Notes
- To use CUDA (if available), omit `--device cpu` or pass `--device cuda`.
- Reproducibility: seeds python, NumPy, and torch.
- The model is intentionally simple and fast; adjust `hidden_size`, `num_layers`, and `epochs` for better accuracy.
